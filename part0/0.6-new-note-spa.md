
# Exercice 0.6 — Nouvelle note dans une SPA

## Diagramme de séquence

```mermaid
sequenceDiagram
    participant browser as Navigateur
    participant server as Serveur

    Note right of browser: L'utilisateur saisit une note

    browser->>server: POST /new_note_spa
    Note right of browser: Corps de la requête en JSON

    activate server
    Note right of server: Enregistre la note
    server-->>browser: HTTP 201 Created
    deactivate server

    Note right of browser: La page ne se recharge pas
    Note right of browser: JavaScript actualise l'affichage
```

## Explication

1. L'utilisateur saisit une note.
2. JavaScript intercepte la soumission du formulaire.
3. Le navigateur envoie une requête POST contenant les données JSON.
4. Le serveur enregistre la note et renvoie une réponse de succès.
5. JavaScript actualise l'affichage sans recharger le document HTML.
