## Objectifs d'apprentissage

- Comprendre le fonctionnement du navigateur et du serveur.
- Comprendre les requêtes HTTP GET et POST.
- Lire et créer des diagrammes de séquence Mermaid.
- Comprendre la différence entre une application traditionnelle et une SPA.

**Technologies étudiées :** HTTP, HTML, JavaScript, JSON et Mermaid.
